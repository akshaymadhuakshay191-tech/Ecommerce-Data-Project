About the Project

This repository contains SQL practice queries using an E-commerce dataset. The questions are organised into three levels: Beginner, Intermediate and Advanced.

Topics Covered

>SELECT & WHERE

>ORDER BY & LIMIT

>Aggregate Functions

>GROUP BY & HAVING

>JOINs

>Subqueries

>Views

>CTEs

>Window Functions

Tools Used

>MySQL

>MySQL WORKBENCH

>GitHub

Purpose

The purpose of this project is to improve SQL skills and practise data analysis using real-world style datasets.
